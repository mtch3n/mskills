# Design

Tokens are in `site/app.css` (`:root`). Use them. Do not write raw colors or sizes in a page.

## Components

- `.shell`: the page grid with the sidebar. Every page uses it.
- `.side`: the sidebar navigation. Each item is an icon and a label.
- `.table`: every data table.
- `.input`, `.button`: form controls. They are 36px tall.

## Rules from review

- Do not add a helper sentence under a heading.
- Do not change the numbers on the dashboard. The finance team reads them.
