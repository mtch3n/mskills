# Product rules

- Supported languages: English and German. Add `?lang=de` to a page address for German.
- Supported viewports: desktop 1280x800 and phone 375x812. Tablets are not supported and are not tested.
- Buttons are compact: a button is never taller than 36px. Small controls get a 44px touch area from the `.hit` class, not from a bigger visual size.
- Spacing uses the tokens in `site/tokens.css` only.
- Every form shows an error message next to a field that fails validation.
